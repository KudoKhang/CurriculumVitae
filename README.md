## 📌 Giới thiệu (Overview)

Bản Curriculum Vitae trực tuyến được thiết kế và tối ưu dành riêng cho vị trí **AI Engineer**, định hướng:
1. **Ứng dụng AI vào quy trình sản xuất phần mềm (AI in SDLC):** Tận dụng các mô hình AI thế hệ mới (LLMs, Autonomous Coding Agents, Model Context Protocol - MCP, Tool Calling) để tự động hóa khâu phân tích, sinh mã, kiểm thử và tài liệu hóa, nhân rộng năng suất phát triển phần mềm.
2. **Thực thi Chuyển đổi số (Digital Transformation) tại Việt Nam:** Số hóa và tự động hóa các quy trình nghiệp vụ thủ công trong nhà máy sản xuất (LPR nhà máy), phân tích video thể thao, tối ưu hóa chi phí hạ tầng máy chủ GPU cho doanh nghiệp và ứng dụng RAG trong giáo dục.

## 🚀 Tính năng nổi bật của Website (Key Features)

- **Thiết kế hiện đại & Tương tác cao:**
  - Giao diện xây dựng trên nền tảng **Tailwind CSS**, hệ thống typography sắc nét với **Inter** (văn bản) và **JetBrains Mono** (mã nguồn, metrics, tech tags).
  - Phân loại kỹ năng trực quan bằng hệ thống **Tech Badges**.
- **Chế độ Sáng / Tối (Light & Dark Mode):**
  - Chuyển đổi nhanh qua nút bấm ở thanh điều hướng trên cùng.
  - Tự động lưu trạng thái vào `localStorage` và đồng bộ với cấu hình hệ thống (`prefers-color-scheme`).
- **Tối ưu in ấn xuất sắc (Print / PDF Ready):**
  - Tích hợp `@media print` chuẩn hóa tài liệu theo khổ **A4**, tự động ẩn thanh công cụ web, chống ngắt trang dở dang (`page-break-inside: avoid`), đảm bảo khi bấm **Print / Save PDF** (hoặc `Ctrl + P`) sẽ xuất ra file PDF chuẩn mực.
- **Tối ưu SEO & Structured Data:**
  - Tích hợp đầy đủ thẻ OpenGraph, Twitter Cards, và Schema.org JSON-LD structured data.

## 🛠️ Chạy cục bộ (Local Development)

Không cần cài đặt build tool phức tạp, chỉ cần chạy một web server tĩnh bất kỳ:

```bash
# Sử dụng Python 3
python3 -m http.server 8000

# Hoặc sử dụng Node.js (npx)
npx serve .
```

Mở trình duyệt tại: `http://localhost:8000`
